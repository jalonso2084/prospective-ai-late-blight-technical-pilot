# Raw outputs not yet recovered into this package

This pre-release package contains **7 of the 11 valid model outputs** as recoverable raw files. The following four valid primary outputs were supplied and validated during the project but are not currently present as standalone source files in the accessible project file store:

- `SP-VF058-P1`
- `SP-VF064-P1`
- `SP-VF068-P1`
- `SP-VF073-P1`

Their reported scores and forecast values are included in `data/pilot_results_reported.csv` and are explicitly marked as **raw JSON not yet repackaged**. They should be recovered from the original run conversations before a public **v1.0** release that claims complete raw-output availability.

No missing JSON has been reconstructed from memory or regenerated.
